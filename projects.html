Munch

team of 5

A federated social network built for CMPUT 404. Each node runs its own server and database, and people on different nodes can follow, like and comment on each other's posts.

  • Python
  • Django
  • Django REST Framework
  • PostgreSQL
  • Heroku
More details
  • Nodes share posts, likes, comments and follow requests by sending them to each other's inbox endpoints.
  • Nodes authenticate to each other with HTTP Basic Auth, and our node federated with other teams' nodes.
  • Posts can be public, friends-only or unlisted, and visibility rules hold across nodes.
  • 113+ tests cover the user stories at the API and model level.
  • My role: full-stack developer. I worked on the backend API and data models, and built the HTML and CSS pages that present the server's data.

Code on GitHub: Munch

EspeonBot

Discord bot

A Discord bot that tracks habits, logs activities, times focus sessions and keeps reminding you until a task is done. It runs around the clock on a hosted server.

  • Python
  • discord.py
  • SQLite
  • pytest
  • GitHub Actions
More details
  • More than 20 commands, organized into cogs for tracking, logging, focus sessions and skips.
  • A scheduled reminder loop that respects each user's preferred reminder hour, with snooze.
  • Records are keyed on a composite user ID, so people in a shared server cannot overwrite each other's data.
  • A duration parser that accepts combined units such as 1h30mi or 2w3d.
  • Logs skipped activities and replies with a roast, with a separate set of roasts for skipped lectures.
  • Tests for the database, commands and helpers run automatically with GitHub Actions.

Code on GitHub: EspeonBot

EventBuddy

team of 6

An Android app for running events, built for CMPUT 301. Organizers create events and check people in with QR codes, entrants join waitlists, and admins moderate users and images.

  • Java
  • Android
  • Firebase
  • Figma
  • draw.io
More details
  • Push notifications go through Firebase Cloud Messaging, sent by a small Node.js and Express service.
  • QR code generation and scanning, plus a map with a marker for each person on an event's waitlist.
  • Admin tools to browse and remove users, images, QR codes and facilities.
  • Planned with UML class diagrams, CRC cards and UI prototypes. Unit tests run automatically with GitHub Actions.
  • My role: Android developer. I designed the interface and system diagrams in Figma and draw.io, implemented model classes and UI components in Java, and wrote the project documentation and meeting notes.

Code on GitHub: EventBuddy

discord-xcode-presence

macOS app

A menu bar app that shows the file you have open in Xcode as your Discord status, with a timer and a button that links to the project's GitHub repo.

  • Python
  • AppleScript
  • pypresence
  • rumps
  • PyInstaller
  • unittest
More details
  • Asks Xcode for the active source file every 5 seconds through AppleScript.
  • Converts SSH git remotes into clean HTTPS links to meet Discord's rules for button links, so a token stored in the remote is never shown.
  • Runs the presence loop on a background thread with automatic reconnection.
  • unittest suites mock subprocess, IPC and network calls, and run in GitHub Actions.

Code on GitHub: discord-xcode-presence
